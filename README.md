# Myankchawla

Act as an **Awwwards level UI UX designer, luxury fashion art director, brand strategist, elite copywriter and senior frontend developer**.

Build a complete, production ready, premium multi page website for **MAYANKCHAWLA Menswear** in one focused implementation. Do not give me a plan. Build the actual website.

### BRAND

The primary brand name is **MAYANKCHAWLA** without a space.

**Menswear** is a smaller secondary descriptor.

Use the already attached horse logo. Black horse logo is the primary identity. Use the gold horse subtly as a signature on selected image cards only.

Theme: **BLACK + WHITE + DEEP MAROON**.

Use black and white as section backgrounds. Use deep maroon primarily for headings on white sections. Keep the visual system extremely restrained and premium.

### VISUAL DIRECTION

The current goal is a **larger than life Indian designer menswear house**, not a generic ecommerce template.

Think cinematic fashion editorial, sophisticated Indian occasionwear, strong masculine presence, beautiful negative space and exceptional photography.

Do not copy Prada, Gucci or Manish Malhotra. Match the level of refinement while creating an original MAYANKCHAWLA identity.

### REAL IMAGES ONLY

Use **only real, high quality Mayank Chawla Menswear imagery sourced from the internet**.

Research these sources:

https://mayankchawla.co.in/

https://www.instagram.com/mayankchawla_menswear/

https://www.perniaspopupshop.com/designers/mayank-chawla

Every fashion image must genuinely show **Mayank Chawla Menswear**.

No stock photos.

No unrelated designer clothing.

No AI generated fashion images.

No low resolution, blurry or visibly compressed images.

Prefer the highest quality source available.

**Important:** wherever a model is used, use imagery where the model is clearly standing and the complete outfit is visible.

Never position text, cards, logos or UI elements over the model's face or important garment details. Carefully art direct every image crop and responsive position.

Keep all image URLs in one central asset configuration so images can easily be replaced later.

### HOMEPAGE

Create a rich but elegant homepage containing:

**Hero**
Full screen premium campaign image or video. Extremely short headline. Model and outfit remain completely visible.

**The House**
Short brand introduction with View More.

**Signature Collections**
Beautiful editorial collection cards using real Mayank Chawla imagery.

**Occasionwear**
A strong visual section establishing occasionwear as a signature.

**Selected Pieces**
Curated premium product cards leading to Shop.

**Craft & Detail**
High quality close up garment details.

**Founder**
A dedicated introduction to Mayank Chawla using a genuine photograph and verified information. Link to The House.

**Celebrities**
Premium cards showing verified celebrities genuinely wearing Mayank Chawla. Use real images only. Minimal text with celebrity name and “IN MAYANKCHAWLA”.

**Journal**
Editorial campaign and fashion story previews.

**Visit The House**
Research the actual Mayank Chawla offline stores through official sources and Google Maps. Use a real image of the actual showroom where available, never a generic store photograph. Include verified address and Get Directions.

**Final Campaign**
Large authentic image and short memorable brand statement.

### SHOP

Make Shop the most premium page.

It should feel like a **curated designer showroom**, not a normal ecommerce catalogue.

Use large photography, generous whitespace, refined grids, subtle borders, elegant hover effects, restrained product information and sophisticated colour swatches.

Include working category/filter controls, product detail pages, size and colour selection where actual data exists, and **Enquire About This Piece** rather than a fake checkout.

### NAVIGATION

Premium header with:

Horse logo
**MAYANKCHAWLA**
small **Menswear**

Navigation:

**Home / Collections / Shop / The House / Journal / Connect**

Keep it minimal and sophisticated.

Create a beautiful matching footer.

### TYPOGRAPHY

Use a strong bold fashion display font similar to **Impact** for headings.

Use one refined secondary font for body copy and UI.

Typography must be authoritative but controlled.

No oversized headings.

No tiny text.

### COPY

Rewrite all copy so it feels **confident, masculine, sophisticated, aspirational, editorial and larger than life**.

Do not use generic AI language or predictable luxury clichés.

Keep headlines short and memorable.

**Never use hyphens anywhere in visible website text.**

### ANIMATION

Use **GSAP and ScrollTrigger** for refined Awwwards level motion.

Include subtle:

Image reveals
Text reveals
Section entrances
Card hover movement
Image scale transitions
Collection interactions
Header transformation on scroll
Smooth page transitions
Tasteful scroll movement

Motion must feel cinematic and expensive, never excessive.

Support reduced motion.

### RESPONSIVE

Desktop, tablet and mobile must all be designed intentionally.

Perfect image cropping, typography, navigation, product grids, spacing, touch interactions and animations.

No horizontal scrolling.

No overlapping elements.

No broken image crops.

No text over faces or important clothing details.

### FINAL REQUIREMENT

Build the entire website **fully ready to run and present**, not a prototype or wireframe.

Prioritise execution over explanation. Do not spend credits generating unnecessary commentary or asking unnecessary questions.

Use real Mayank Chawla imagery, exceptional composition, restrained typography, strong storytelling and premium motion.

The final impression should be:

**MAYANKCHAWLA is not simply selling clothes. It is presenting a world of Indian designer menswear.**
